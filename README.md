\# Retail Sales Data Analysis Using Python and Apache Spark



\## Project Overview

This project analyzes retail sales transactions using Python and Apache Spark (PySpark). It demonstrates data exploration, data cleaning, key performance indicator (KPI) calculation, and sales aggregation by product category, month, and region.



\## Objectives

\- Explore and clean retail transaction data.

\- Calculate total revenue, orders, and units sold.

\- Identify high-performing product categories.

\- Analyze monthly sales trends.

\- Compare regional sales performance.

\- Demonstrate DataFrame-based analysis using Apache Spark.



\## Technologies Used

\- Python

\- Pandas and NumPy

\- Matplotlib and Seaborn

\- Apache Spark (PySpark)

\- Google Colab

\- GitHub



\## Dataset

The project uses a sample dataset containing 1,200 synthetic retail transactions. It includes order IDs, product categories, products, quantities, prices, discounts, regions, dates, and revenue.



\*\*Note:\*\* The dataset is synthetic and intended for educational use. It does not represent actual retail business transactions.



\## Implementation

1\. Generate and inspect the dataset.

2\. Check for missing values and duplicates.

3\. Clean and prepare the data.

4\. Calculate sales KPIs.

5\. Visualize category, monthly, and regional performance.

6\. Load the CSV into Spark and perform grouped aggregations.



\## How to Run

1\. Open the `.ipynb` notebook in Google Colab.

2\. Run the notebook cells in order.

3\. Install PySpark when required using `pip install pyspark`.

4\. Ensure the CSV dataset is available in the Colab runtime.

5\. Review the analysis tables and charts.



\## Big Data Scope

Apache Spark is used in local mode to demonstrate Spark DataFrame operations. This educational implementation does not use a multi-node cluster or establish distributed processing across multiple machines.
